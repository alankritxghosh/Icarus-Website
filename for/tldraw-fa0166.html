Questions a new contributor would ask

answeredWhy did tldraw root the reactions query at comment rather than comment_reaction?

Rooting the query at comment ensures the file-access gate remains one correlated-subquery hop from the root, preventing the query from traversing large file_state and group_file tables. This optimization reduces materialization time from ~150s to ~162ms, preventing the sync connection from timing out.

answeredWhy is the Zero auth refresh scheduled from the token's own expiry?

The Zero auth refresh is scheduled from the token's own expiry to ensure the refresh cadence follows the session-token lifetime rather than a hardcoded guess, preventing Zero connections from being torn down by tokens that expire while in use.

answeredWhy were the Zero feature flags and the frontend polyfill removed?

The Zero feature flags and frontend polyfill were removed because production has been using the real Zero client 100% of the time, making the second, unmaintained sync path unnecessary.

answeredWhy does the comment tool stay active while the composer is open?

The comment tool is kept active while the composer is open to ensure the right-hand panels remain stable during the placement interaction. This prevents the style panel from materializing mid-interaction and ensures the sidebar remains closed for the duration of the placement.

pr9837
answeredWhy are orphaned preview certificate packs pruned and the deletion grace period dropped?

Orphaned certificate packs are pruned to stop SSL certificates from piling up on the tldraw.xyz zone, as deleting a worker with a custom domain leaves its edge certificate behind. The 2-day deletion grace period was removed so that preview infrastructure is pruned on the first nightly run after a PR closes.

answeredWhy does tldraw use a reactive signals store instead of React state for the editor?

tldraw uses a reactive signals store because it provides fine-grained reactivity, high performance through lazy evaluation and efficient dependency tracking, and automatic updates for derived values and side effects.
