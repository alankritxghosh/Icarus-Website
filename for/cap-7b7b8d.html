answeredWhy did Cap migrate analytics from PostHog to self-hosted OpenPanel?

Cap migrated to self-hosted OpenPanel to enable first-party proxying of analytics (making them ad-blocker resistant), improve server-side event delivery performance by moving it off the response path, and resolve desktop credential exposure issues.

answeredWhy does the transcript editor edit videos by word rather than by timestamp?

The transcript editor uses word-level editing because stored transcripts are immutable and expressed in the original media timeline, allowing the system to remap captions and perform edits by remapping these words through the video's cumulative edit specification rather than re-transcribing.

answeredWhy was lifetime memory growing from the macOS permission check?

The memory growth was caused by the macOS screen-recording permission check running a full SCShareableContent enumeration on threads that lacked an autorelease pool. Because this check was triggered repeatedly by polling callers throughout the process lifetime, the object graph from each call was leaked permanently.
