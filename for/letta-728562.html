answeredWhy does the server propagate retry events to the listener?

The server propagates retry events to the listener to convert server retry_message chunks into a canonical retry lifecycle message, which allows for client rendering, diagnostics, and visibility of retries in the transcript.

answeredWhy does the client tool loader only load tools named in the allowlist?

The allowlist is used to filter the tools available to a client, ensuring that only authorized tools are loaded and accessible during a session. This prevents issues where requested tools not present in the default base would otherwise result in the agent silently finding nothing instead of returning an error.

answeredWhy does a wedged HTTP read get aborted after a terminal SSE sequence?

A wedged HTTP read is aborted because the client's iterator hangs indefinitely when the server fails to report an EOF for the HTTP response body, even after sending the terminal SSE sequence. The guard detects this sustained silence following the terminal sequence and aborts the stream controller to allow the SDK to proceed with the data it has already received.

answeredWhy do direct turns stay on process transport?

Direct turns are routed through the process-scoped transport to ensure that if a WebSocket connection closes during approval, the turn can continue through a replacement connection or another subscribed client. This change ensures the transport's open state follows the current connection set rather than being tied to the originating WebSocket.

answeredWhy does cron fall back to a local schedule when Cloud cannot reach this computer?

Cron falls back to a local schedule because the computer is not in the environments registry, meaning the Cloud scheduler cannot reach it. Storing the schedule locally is the only way to ensure the work continues to execute where the conversation lives.

answeredWhy did MessageChannel become gateway-owned?

MessageChannel became gateway-owned to remove the listener-owned built-in registration and duplicate implementation, allowing the tool to work for every routed conversation, including scheduled turns.

answeredWhy are repeated outbound actions deduplicated in channels?

Repeated outbound actions are deduplicated because each new tool-call ID currently executes the channel adapter again, which can result in one inbound message producing several identical external replies. Deduplication ensures that identical calls within one active channel turn share the first successful result.

answeredWhy is Letta built as a stateful agent instead of a stateless one?

Letta Code is built as a stateful agent so that it can possess memory, identity, and a sense of experience over time, allowing it to learn and evolve by rewriting its own memory, skills, and prompts.
