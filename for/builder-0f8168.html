Questions a new contributor would ask

answeredWhy did Gen 2 Angular SDK text block edits revert in the Visual Editor?

The issue occurred because the props.content update hook in the Angular SDK was compiled into an effect() that tracked all signal reads within its body, causing it to re-run on unrelated context updates. This resulted in the original page-load content being incorrectly merged over edits made in the Visual Editor.

answeredWhy did Builder stop injecting duplicate A/B test init scripts?

Builder stopped injecting duplicate A/B test init scripts by gating the script emission so it only renders when a Content component actually renders A/B variants, and by making the script idempotent and self-removing on hydration targets.

answeredWhy does the Smartling plugin skip nested fields for translation?

The Smartling plugin previously skipped nested fields because it treated localized arrays or objects as a single non-string value, which Smartling cannot translate. Because Smartling's upload directives only accept string values, the plugin failed to extract the individual string leaves within those nested structures.

answeredWhy was tslib upgraded from 1.10.0 to 2.1.0?

The upgrade was necessary because the package's compiled output uses the __spreadArray helper, which was introduced in tslib 2.1+ following a TypeScript upgrade. Updating the dependency ensures the declared version matches the requirements of the compiled code, preventing blocking build errors for consumers.
