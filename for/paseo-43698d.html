Questions a new contributor would ask

answeredWhy does the todo tool map results to TodoListCard instead of unknown JSON?

The todo tool results previously rendered as raw JSON because the Pi provider's tool-call-mapper did not recognize the "todo" tool name, causing it to fall through to the "unknown" case. PR #2945 fixed this by adding a dedicated mapper to parse these results into TodoListCard timeline items.

answeredWhy does the native terminal keep wide characters two columns wide?

The native terminal previously treated wide characters as a character followed by a literal space, which caused rendering issues and column misalignment. The fix ensures that wide characters are kept two columns wide by treating a reported width of 1 on an intrinsically double-width character as lost information and falling back to the spacer cell, while skipping that spacer cell during snapshot replays.

answeredWhy does the Command Center rank results by match quality?

The Command Center ranks results by match quality to ensure that visible labels outrank hidden keywords and that the first result is the best match for the user's query. This prevents confusing scenarios where obscure synonyms or hidden hints appear above relevant, readable options.

answeredWhy do agents run with their directory's environment?

Agent processes are spawned by the daemon rather than a shell, meaning they do not automatically receive the per-directory setup that an interactive terminal gets. Running agents with their directory's environment ensures they have access to the tools and configurations (such as those defined in a .envrc file) required for their operation.

answeredWhy is the sidebar resize handle made usable by touch?

The sidebar was previously not resizable by touch because the drag handle was positioned partially outside the sidebar's bounds, and native platforms clip hit-testing to a view's bounds. Additionally, the original handle lacked a visible affordance for touch, as the hover-based highlight did not function on native.

answeredWhy are markdown line heights derived from the font-size ramp?

Markdown line heights are derived from the font-size ramp to prevent wrapped headings from being sliced or overlapping when the UI font size is increased. This ensures the line height always clears the glyph box, particularly for CJK text which has taller metrics than Latin text.

answeredWhy are usage percentages configured as used or remaining?

Usage percentages are configured as used or remaining to clarify whether the displayed value represents consumed capacity or the amount of capacity left. This allows users to read values like '7% used' directly without having to infer the meaning from the bar direction.

answeredWhy can Deploy Hub configurations be deployed from the CLI?

Deploying Hub configurations from the CLI allows users to keep deployment explicit by using the Hub origin, organization API key, project slug, and YAML file directly, avoiding the need to create a second login or credential system.

answeredWhy is Paseo built as a desktop app instead of a browser extension?

Paseo is built as a desktop app to provide agents with access to real browser tabs, allowing them to open pages, click, type, verify work, and maintain session state. This browser automation capability is specific to the desktop environment and is not available on mobile or web platforms.
